# v0.1.12 更新说明

- 新增黎洁特、未知开拓者佛里蒂丝的伤害计算数据与技能图标。
- 修复修尼尔新版 S3：基础固定伤害 5,000，拥有“不屈”时为 15,000；移除旧版技能使用次数逻辑。
- 新增“不屈”“神圣”“攻击任务”“防御任务”“星辰知识”等战斗状态，并接入对应的防御、生命、攻击和额外伤害计算。
- 新增神器“光与暗”的范围攻击额外伤害计算和等级成长；“星辰知识”与追击套的额外伤害提升按加法叠加。

- 程序检查 GitHub Releases 更新后，会直接显示该版本的 Release 标题、更新说明和 Release 链接。
- 新增计算器便携版同步维护文档与白名单脚本，避免从 `e7-tools` 同步时误带入图鉴页面。
