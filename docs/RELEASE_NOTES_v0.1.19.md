新增梅铃和火龙宝石，并修复 Windows 界面缩小后的右侧内容裁切。

- 梅铃显示 S2、S2(热情1)、S2(热情2) 三行伤害，倍率为 1.0、1.7、2.4，技能强化等级联动。
- 攻击提升和攻击大提升手动选择；防守方按面板攻击计算梅铃的开局防御，防御提升/降低及攻击 Buff 不改变这项防御。
- 火龙宝石支持神器选择、图片和等级对应的攻击增益；支持“梅玲”别名搜索。
- 界面设置支持 50%–150% 缩放滑块和数值输入，窗口尺寸及位置记忆；缩小后内容完整显示，左右边距紧凑。

Windows 0.1.19。提供便携 EXE 与自动更新 ZIP；ZIP 只附默认别名，不包含个人装备预设和配置。

验证：207 项单元测试通过，生产构建及原生窗口缩放检查通过。
