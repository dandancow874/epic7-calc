# Epic7 Damage Calc v0.1.22

- 新增神器「快速筛选」：按当前伤害表选择技能及命中状态，以不带神器为基准比较实际伤害，按增伤排序，并同时显示闪避增幅。包含神器追加伤害与使用装备预设时的基础属性变化。
- 特别的草莓蛋糕、共度的季节、灿烂的永恒不参与快速筛选，普通手动选择保留；未接入计算的神器明确标记。
- 新增穿透提升 / 穿透大幅提升，连续点击循环切换；按单体或群体自动计算，与技能、套装、神器穿透按剩余防御相乘。常用栏在爆伤提升后显示魄力、狂气、穿透提升。
- 修正战术型可丽的 S1 出血激爆输入与 S3 满强化伤害增幅（30%）。
- 保留 Windows 窗口、缩放、更新器与现有个人配置。便携压缩包仅含 EXE，不带个人 data 文件。

共享计算内容同步自 e7-tools 2026-11-18。解压后替换旧 EXE 即可。
